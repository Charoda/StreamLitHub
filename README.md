# Предсказание цены автомобиля

Проект по предсказанию рыночной стоимости подержанных автомобилей на основе технических характеристик и категориальных признаков. В ходе работы были проведены исследование данных, построение и сравнение нескольких моделей регрессии, отбор признаков и развёртывание Streamlit-приложения для демонстрации результатов.

## Исходные данные

Набор данных содержит информацию о 6999 автомобилях с 13 признаками:

- year – год выпуска
- km_driven – пробег (км)
- fuel – тип топлива
- seller_type – тип продавца
- transmission – коробка передач
- owner – количество владельцев
- mileage – расход топлива (км/л)
- engine – объём двигателя (куб. см)
- max_power – мощность (л.с.)
- torque – крутящий момент (текст)
- seats – количество мест
- selling_price – целевая переменная (цена в рублях)

## Первичный анализ данных (EDA)

- Пропуски и очистка: из столбцов mileage, engine, max_power, torque и seats были извлечены числовые значения (с помощью регулярных выражений), пропуски заполнены медианой.
- Корреляционный анализ:
  - Сильная положительная корреляция между year и engine (новые автомобили имеют более современные двигатели).
  - Связь между max_power, engine и torque (закономерно, так как эти параметры описывают двигатель).
  - Обратная корреляция между year и km_driven – чем старше автомобиль, тем выше пробег.
- Выбросы: обнаружены значительные выбросы в km_driven и целевой переменной selling_price, которые потенциально могут искажать обучение.

## Обучение моделей

### 1. Линейная регрессия на вещественных признаках

- Признаки: year, km_driven, mileage, engine, max_power, seats
- Метрики:
  - R2 = 0.594
  - MSE = 233 297 703 374.95
  - RMSE = 0.771
  - MAE = 224 473 руб.

Коэффициенты (интерпретация при изменении на 1 std):

| Признак     | Коэффициент | Влияние на цену |
|-------------|-------------|-----------------|
| year        | +37 322     | увеличение      |
| seats       | -23 640     | уменьшение      |
| max_power   | +10 203     | увеличение      |
| mileage     | +7 221      | увеличение      |
| engine      | +126        | увеличение      |
| km_driven   | -0.735      | уменьшение      |

Наиболее информативные признаки – max_power и km_driven.

### 2. Попытка улучшения с помощью Lasso (L1-регуляризация)

Lasso была применена с различными значениями alpha в диапазоне [1e-5, 1.0]. Модель демонстрировала сильное переобучение:
- Разница RMSE между train и val составляла ~39 800 (около 12%).
- Ни один коэффициент не был занулён, регуляризация не сработала как отбор признаков.

### 3. Подбор гиперпараметров через GridSearchCV (только вещественные)

- Модели: Ridge, ElasticNet
- Сетка: alpha ∈ {0.1, 1, 5, 10, 50, 100} для Ridge; для ElasticNet дополнительно l1_ratio ∈ {0.2, 0.5, 0.8}
- Лучшие параметры (Ridge): alpha = 0.1
- R2 на кросс-валидации: около 0.616 (10 фолдов)
- Коэффициенты:
  - max_power: 291 402
  - year: 151 577
  - engine: 87 610
  - km_driven: -61 082
  - seats: -32 013
  - mileage: 19 251

Все коэффициенты ненулевые – регуляризация не обнуляла признаки.

### 4. Добавление категориальных признаков (One-Hot Encoding)

После кодирования категорий (fuel, seller_type, transmission, owner, а также seats как категориальный) и масштабирования числовых признаков была проведена кросс-валидация с Ridge (10 фолдов).

- Количество признаков после OHE: 23
- Лучший alpha: 5
- R2 на кросс-валидации: 0.6165
- R2 на отложенной выборке (hold-out): 0.6362

Коэффициенты (топ-5 по абсолютной величине):

| Признак                         | Коэффициент |
|---------------------------------|-------------|
| transmission_Manual             | -285 819    |
| max_power                       | +294 975    |
| seller_type_Trustmark Dealer    | -87 976     |
| seller_type_Individual          | -74 234     |
| owner_Test Drive Car            | +668 747    |

- Количество ненулевых коэффициентов: 22 из 23 (один признак seats_14 обнулился из-за малой встречаемости).

### 5. Бизнес-метрика

Для лучшей модели (Ridge с alpha=5 и категориальными признаками) вычислена доля предсказаний, которые отличаются от реальной цены не более чем на 10%.

> 22.03% автомобилей были предсказаны с погрешностью ≤10%.

## Streamlit-приложение

Интерактивное веб-приложение позволяет:

- Загрузить данные для анализа (CSV-файл или по ссылке) и визуализировать:
  - Описание данных (статистика, частотные таблицы)
  - Корреляционную матрицу числовых признаков
  - Гистограммы распределений
  - Категориальные графики (топ-10 значений)
- Загрузить обученную модель (файл .pkl с объектами инференса: модель, scaler, encoder, медианы, списки колонок)
- Загрузить тестовые данные (CSV или ссылка) и получить предсказания с возможностью скачать результаты.
- Посмотреть значимость весов модели в виде круговой диаграммы.

### Запуск

```bash
python -m streamlit run stream1.py


### Выводы
- Добавление категориальных признаков и One-Hot кодирование позволило повысить R2 с ~0.59 до 0.636 на отложенной выборке.

- Регуляризация (Lasso, Ridge) не привела к значительному отбору признаков – все основные признаки остались в модели.

- Наибольшее влияние на цену оказывают мощность двигателя, год выпуска, тип коробки передач и тип продавца.

- Приложение Streamlit готово к использованию для загрузки новых данных и получения предсказаний в реальном времени.
